# taskhub-monolith
A full-stack monolithic task management application built with a modern cloud-native architecture. 
The application features a responsive React frontend and a high-performance Python FastAPI backend, fully containerized using Docker for seamless deployment and scalability.


🚀 Tech Stack:
⚛️ React Frontend
⚡ FastAPI Backend
🐳 Docker & Docker Containers
🌐 Nginx Reverse Proxy
☁️ Microsoft Azure Virtual Machine
🗄️ Azure SQL Database
🔌 pyodbc + ODBC Driver 18
